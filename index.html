01 / EXPLORE

The bigger picture

See films together in a poster grid, or browse one at a time with arrow keys and swipes. Open any title on IMDb for more.

02 / FIND

Your next watch

Highest IMDb rating comes first by default. Sort by Rotten Tomatoes rating, year, or title, and search or filter acting, writing, producing, and directing credits. Each poster shows their roles, and remaining credits load automatically.

03 / COMPARE

Two scores. One glance.

Compact Rotten Tomatoes links sit beside IMDb scores. A red tomato means Fresh (60% or higher); a green splat means Rotten (below 60%). Missing scores stay hidden. Select a critic score to open Rotten Tomatoes.

Install the standalone version

The Chrome Web Store listing is not published yet. Until it is available, install the downloadable package in Chrome:

  1. Download and extract

    Download the extension ZIP and extract it to a folder you’ll keep on your computer.

  2. Load the extension

    Open chrome://extensions, enable Developer mode, click Load unpacked, and select the extracted folder containing manifest.json.

  3. Browse IMDb

    Open or refresh a person’s IMDb page and click Browse posters. No Tampermonkey installation is required.

Already using the userscript? You can switch to the extension. Cached ratings are separate, and installing both shows only one poster browser. To choose which version runs, disable the other and refresh IMDb.

A better view.

Prefer the original method? Install Tampermonkey once, then add the script. You’ll find the same Browse posters button on IMDb person pages.

Read the full guide ↗

  1. Install Tampermonkey

    Add Tampermonkey from the Chrome Web Store.

  2. Allow user scripts

    Type chrome://extensions in Chrome’s address bar. Find Tampermonkey, open Details, and enable Allow User Scripts.

  3. Copy, paste, save

    Copy the script below. Open Tampermonkey from Chrome’s Extensions menu and select Create a new script…. Replace all the example code with the copied script, then press Ctrl + S.

    Download the script instead

  4. Go exploring

    Allow access to www.rottentomatoes.com if Tampermonkey asks, then open or refresh a person’s IMDb page and click Browse posters. The grid opens with the highest IMDb ratings first. Select a poster to view it on its own.

Already installed? Keep your version up to date.

Standalone extension: for this downloadable version, download and extract the latest ZIP into your extension folder, then click its reload button at chrome://extensions and refresh IMDb.

Userscript: copy the latest script above, open your existing IMDb Poster Browser script in Tampermonkey, replace its contents, and save with Ctrl + S. Keep only one copy enabled, then refresh IMDb.

Both versions load Rotten Tomatoes ratings as posters come into view and cache them for 24 hours. Sorting by Rotten Tomatoes loads ratings for all matching titles; progress appears above the posters.

Can’t see the button? For the extension, check that it is enabled and allowed to run on IMDb, then refresh. For the userscript, check that it is enabled, Allow User Scripts is on, and Tampermonkey can run on IMDb. Tampermonkey permission help ↗
