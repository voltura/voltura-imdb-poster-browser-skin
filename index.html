Turn an actor’s IMDb page into a wall of movie posters. Compare IMDb and Rotten Tomatoes ratings, then explore their films in a grid or one poster at a time.

Version 1.4.2 · Free Chrome userscript · Requires Tampermonkey

01 / EXPLORE

The bigger picture

See films together in a poster grid, or browse one at a time with arrow keys and swipes. Open any title on IMDb for more.

02 / FIND

Your next watch

Highest IMDb rating comes first by default. Sort by Rotten Tomatoes rating, year, or title, and search or filter acting credits. Remaining credits load automatically.

03 / COMPARE

Two scores. One glance.

Compact Rotten Tomatoes links sit beside IMDb scores. A red tomato means Fresh (60% or higher); a green splat means Rotten (below 60%). Missing scores stay hidden. Select a critic score to open Rotten Tomatoes.

Get started

Your browser.
A better view.

Install Tampermonkey once, then add the script. You’ll find a new Browse posters button on IMDb actor pages.

Read the full guide ↗

  1. Install Tampermonkey

    Add Tampermonkey from the Chrome Web Store.

  2. Allow user scripts

    Type chrome://extensions in Chrome’s address bar. Find Tampermonkey, open Details, and enable Allow User Scripts.

  3. Copy, paste, save

    Copy the script below. Open Tampermonkey from Chrome’s Extensions menu and select Create a new script…. Replace all the example code with the copied script, then press Ctrl + S.

    Download the script instead

  4. Go exploring

    Allow access to www.rottentomatoes.com if Tampermonkey asks, then open or refresh an actor’s IMDb page and click Browse posters. The grid opens with the highest IMDb ratings first. Select a poster to view it on its own.

Already installed? Update your existing script.

Copy the latest script above, open your existing IMDb Poster Browser script in Tampermonkey, replace its contents, and save with Ctrl + S. Keep only one copy enabled, then refresh IMDb.

Rotten Tomatoes ratings load as posters come into view and are cached for 24 hours. Sorting by Rotten Tomatoes loads ratings for all matching titles; progress appears above the posters.

Can’t see the button? Check that the script is enabled, Allow User Scripts is on, and Tampermonkey can run on IMDb. Refresh the actor’s page. Permission help ↗

By Voltura. Independent of IMDb, Rotten Tomatoes, and Tampermonkey. Film information and poster artwork come from IMDb; critic scores come from Rotten Tomatoes. Changes to either site may affect the script.
