Get started

Your browser.
A better view.

Install Tampermonkey once, then add the script. You’ll find a new Browse posters button on IMDb actor pages.

Read the full guide ↗

  1. Install Tampermonkey

    Add Tampermonkey from the Chrome Web Store.

  2. Allow user scripts

    Type chrome://extensions in Chrome’s address bar. Find Tampermonkey, open Details, and enable Allow User Scripts.

  3. Copy, paste, save

    Copy the script below. Open Tampermonkey from Chrome’s Extensions menu and select Create a new script…. Replace all the example code with the copied script, then press Ctrl + S.

    Download the script instead

  4. Go exploring

    Open or refresh an actor’s IMDb page and click Browse posters in the bottom-right corner. Switch to Poster grid to see the collection.

Can’t see the button? Check that the script is enabled, Allow User Scripts is on, and Tampermonkey can run on IMDb. Refresh the actor’s page. Permission help ↗

By Voltura. Independent of IMDb and Tampermonkey. Film information and poster artwork come from IMDb. The script uses credits available on the page; IMDb changes may affect it.
