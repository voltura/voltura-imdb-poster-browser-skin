Install from the Chrome Web Store

Now available on the Chrome Web Store, with automatic updates through Chrome.

  1. Open the store listing

    Click Add to Chrome above to open Voltura IMDb Poster Browser on the Chrome Web Store.

  2. Add the extension

    On the store page, click Add to Chrome, then confirm with Add extension.

  3. Browse IMDb

    Open or refresh a person’s IMDb page and click Browse posters. No Tampermonkey installation is required.

Already using the userscript? You can switch to the extension. Cached ratings are separate, and installing both shows only one poster browser. To choose which version runs, disable the other and refresh IMDb.

Before you browse

What does IMDb Poster Browser do?

It adds a Browse posters button to IMDb person pages. Open it to explore acting, writing, producing, and directing credits in a poster grid or one poster at a time. Search titles and sort by rating, release year, or title.

Is the Chrome extension free?

Yes. Voltura IMDb Poster Browser is free, with no account, subscription, or API key required. Install it from the Chrome Web Store.

Does it work on a phone?

The Chrome extension is for Chrome on a computer. Chrome on Android and iPhone does not support installing this extension.

Why are some Rotten Tomatoes scores missing?

Scores appear when a Rotten Tomatoes result matches the film’s title and release year. Ratings load as posters come into view; sorting by Rotten Tomatoes loads ratings for all matching titles. Unavailable scores stay hidden, and site changes may affect matching.

Do I need Tampermonkey?

No. The standalone Chrome extension works on its own and updates automatically through Chrome. The Tampermonkey userscript remains available as an alternative with the same features.

What data does it use?

The extension processes IMDb filmography content and stores rating matches locally. Film-title queries go directly to Rotten Tomatoes to retrieve critic scores. Read the privacy policy for details.

Already installed? Keep your version up to date.

Chrome Web Store extension: Chrome updates it automatically. If you previously installed the ZIP, remove or disable that unpacked copy at chrome://extensions, install from the store, and refresh IMDb. Removing the old copy also removes its cached ratings.

Manual installation: prefer an unpacked extension? Download the extension ZIP, extract it to a folder you’ll keep, then open chrome://extensions, enable Developer mode, and select Load unpacked. Choose the folder containing manifest.json. To update, extract the latest ZIP into the same folder, reload the extension, and refresh IMDb.

Userscript: copy the latest script above, open your existing IMDb Poster Browser script in Tampermonkey, replace its contents, and save with Ctrl + S. Keep only one copy enabled, then refresh IMDb.

Both versions load Rotten Tomatoes ratings as posters come into view and cache them for 24 hours. Sorting by Rotten Tomatoes loads ratings for all matching titles; progress appears above the posters.

Can’t see the button? For the extension, check that it is enabled and allowed to run on IMDb, then refresh. For the userscript, check that it is enabled, Allow User Scripts is on, and Tampermonkey can run on IMDb. Tampermonkey permission help ↗
