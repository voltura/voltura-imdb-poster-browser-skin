Privacy policy

Effective 1 November 2026 · Chrome extension and Tampermonkey userscript, version 1.5.1

Voltura IMDb Poster Browser is provided by Voltura AB. It displays IMDb filmographies as posters and retrieves Rotten Tomatoes critic scores. It is free and requires no account. Both versions provide the same browsing features.

IMDb page content

On IMDb person pages, the software reads the person’s name and filmography information, including title IDs, titles, years, credit categories, roles, ratings, and poster URLs. It processes this information in your browser to display, search, filter, and sort posters. It can expand IMDb’s credit sections to load remaining credits. It does not send this filmography to Voltura.

Requests to other websites

Poster images load directly from IMDb’s Amazon-hosted image servers. When you open the poster browser, Rotten Tomatoes scores load for visible titles. Selecting Rotten Tomatoes sorting requests scores for all matching titles. These requests send each film or series title as a search query directly to www.rottentomatoes.com. Results are matched locally by title, year, and title type.

Rotten Tomatoes requests omit cookies and authentication credentials. The receiving websites still receive ordinary network information such as your IP address. IMDb and its image hosts handle page, credit, and image requests under their own policies. Opening an IMDb or Rotten Tomatoes link is normal navigation and is subject to that website’s policies. Text entered in the poster browser’s title-filter field is processed locally and is not sent as a separate search query.

Local cache and retention

The standalone extension stores score results, matched URLs, IMDb title IDs, titles, years, title types, and expiry times in chrome.storage.local. The userscript uses Tampermonkey’s script storage. These caches are separate and are not synchronized by the software.

Successful lookups, including results without a matching score, are reused for up to 24 hours. Failed requests may be remembered in memory for one minute. Expired results are not reused; the extension removes expired stored records when it next starts on a person page. Storage errors do not prevent poster browsing.

To remove the extension’s cache, uninstall the extension. To remove the userscript’s cache, delete the script and its stored data in Tampermonkey. Your browser or userscript manager may retain data in backups you separately configure.

Permissions and data use

The extension runs on IMDb person pages, uses local storage for rating caches, and requests access to Rotten Tomatoes for critic scores. It does not read unrelated websites, passwords, private messages, payment information, or your browser’s history database.

There is no analytics, advertising, tracking SDK, or developer-operated backend in the extension or userscript. Voltura does not receive, sell, or use your filmography browsing data for advertising. Data is used only to provide the poster browser and its ratings. All executable extension code is bundled with the download.

This website

The product and privacy pages are hosted by GitHub Pages. Visiting them makes ordinary requests to GitHub and any domain delivery infrastructure. Downloading the extension or userscript does not send subsequent extension browsing activity to this website. See GitHub’s privacy statement.

Contact and changes

For support or privacy questions, open an issue in the project repository. Do not include private information in a public issue. Future changes to data handling will be reflected on this page.

This project is independent of IMDb, Rotten Tomatoes, and Tampermonkey.
